# com.viaoa.annotation.OAProperty

## Purpose

Metadata describing a simple (non-link) property of an {@link OAObject}. Generated by OABuilder and consumed by {@link OAPropertyInfo}. The annotation defines validation rules, formatting, UI presentation, encryption, unique constraints, min/max lengths, and behavior flags (e.g., submit fields, status fields, SHA hashing). Functional Areas Validation: required, min/max length, decimal places, allowed/invalid characters, uniqueness, case rules. Formatting: display length, format string, UI column

## Architectural Role

OAProperty is a annotation in the oa annotation contract area. Its invariants should be interpreted through the package role: Defines the annotations that generated and hand-written model classes use to declare metadata.
