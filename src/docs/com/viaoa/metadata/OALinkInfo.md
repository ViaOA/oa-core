# com.viaoa.metadata.OALinkInfo

## Purpose

Metadata definition describing a relationship (link) between two OAObject types. OALinkInfo specifies the cardinality (ONE or MANY), the reverse link name, foreign key mapping, and behavioral rules for maintaining referential integrity in the OA model. Link metadata is generated by OABuilder from the application model and is used throughout the OA runtime to enforce automatic bidirectional consistency, lazy loading, and cascade behavior without requiring manual coding by the application develope

## Architectural Role

OALinkInfo is a class in the oa metadata model area. Its invariants should be interpreted through the package role: Stores annotation-derived class, property, link, calc, method, and model metadata used by runtime services.
