# com.viaoa.metadata.OAMethodInfo

## Purpose

Metadata descriptor for a method on an OAObject type. OAMethodInfo identifies a Java method and its signature so the OA runtime can invoke it dynamically for triggers, lifecycle callbacks, and calculated property evaluation. Method metadata is generated by OABuilder from the application model or discovered through reflection during metadata initialization. It enables the OA runtime to integrate behavior directly into the OA model without requiring hard-coded registration or lookup logic. OAMetho

## Architectural Role

OAMethodInfo is a class in the oa metadata model area. Its invariants should be interpreted through the package role: Stores annotation-derived class, property, link, calc, method, and model metadata used by runtime services.
